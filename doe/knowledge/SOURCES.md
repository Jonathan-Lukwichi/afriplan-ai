# Knowledge sources

Reference material gathered for `BOQ_KNOWLEDGE.md`. Each PDF has a `.txt` copy beside it
(text extracted page by page, `===== Page N =====`) so it can be searched and read without the PDF.
Third-party material: kept out of git (the repo is public).
